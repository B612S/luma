# Vendored KDE mpvqt

This directory contains a vendored copy of KDE's [mpvqt](https://invent.kde.org/libraries/mpvqt),
based on upstream **v1.2.1** (tag `v1.2.1`).

Upstream license: LGPL-2.1-only OR LGPL-3.0-only OR LicenseRef-KDE-Accepted-LGPL.
Keep the SPDX headers in the vendored files intact.

## Local modification policy

Luma may modify the vendored files when their license allows it — and it does. Every
modified upstream file keeps its SPDX header and carries a `Modified for Luma` comment at
the top listing the changes relative to upstream mpvqt v1.2.1. Keep this README in sync
when the list changes.

Prefer implementing behaviour in Luma's own classes (for example by subclassing
`MpvItem`) over editing the vendored code, but when a vendored fix is needed, document it
in the file.

## Modified upstream files

| File | Summary |
| --- | --- |
| `mpvabstractitem.cpp` | Uses an explicit `mpv_render_context *` instead of `auto` for the empty render context. |
| `mpvcontroller.cpp` | Includes Luma's `mpv.conf`, forces mpv playback and embedding/performance properties, leaves the stream cache to `MpvItem::setSource()`, frees caller-created `mpv_node`s, handles unavailable properties safely, and exposes `setLogLevel()` for the optional `mpv.log`. |
| `mpvcontroller.h` | Declares `setLogLevel()` for the optional `mpv.log`. |
| `mpvrenderer.cpp` | Wayland-only display setup, casting/video-off guard, framebuffer clearing, clamped FBO sampling, no `ready()` emission. |
| `mpvrenderer.h` | Removed the unused `m_isFramebufferReady` flag; added a required include. |

The detailed change lists are in the comment block at the top of each file.

## Unmodified upstream files

These files match upstream mpvqt v1.2.1:

- `mpvabstractitem.h`
- `mpvabstractitem_p.h`
- `mpvcontroller.h`
- `mpvcontroller_p.h`

## Luma-specific files (not in upstream mpvqt)

- `MpvItem.hpp` / `MpvItem.cpp` — QML player item: playback controls, casting guards,
  cropping, thumbnail requests and stream helpers. Part of Luma itself
  (GPL-3.0-or-later), not vendored third-party code.
- `FrameDecoder.hpp` / `FrameDecoder.cpp` — background thumbnail decoding with FFmpeg.
  Part of Luma itself (GPL-3.0-or-later).
- `mpvqt_export.h` — export-macro shim replacing the header generated by upstream CMake;
  kept under the same license as the vendored mpvqt sources.
