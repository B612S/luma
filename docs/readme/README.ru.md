<h1 align="center">Luma</h1>

<p align="center">

## Возможности

- **mpv внутри** — воспроизводит практически любые видео- и аудиоформаты без
  дополнительных кодеков.
- **Несколько плейлистов** — вкладки с созданием, переименованием, удалением и очисткой,
  перетаскивание записей, добавление файлов или целой папки, «Добавить в плейлист»
  из меню записи.
- **Настройка субтитров** — шрифт, размер, полужирный, цвет текста и обводки, толщина
  обводки, фон, положение по вертикали, переопределение стиля ASS; применяется к mpv
  сразу.
- **Ссылки через yt-dlp** — откройте ссылку из меню, Luma получит прямой поток через
  `yt-dlp` и воспроизведёт его в mpv с обычной перемоткой. Название видео показывается
  в уведомлении и плейлисте. SOCKS-прокси работает через локальный HTTP-мост, поэтому
  mpv не обходит прокси.
- **Chromecast** — трансляция на ТВ в локальной сети (поиск через `avahi-browse`,
  перекодирование в HLS через `ffmpeg`).
- **Картинка в картинке** — `P` или пункт контекстного меню превращает окно в
  маленький плеер без рамок (его можно тащить и растягивать; пауза, перемотка, время,
  громкость, возврат) и обратно.
- **Подсказка по клавишам** — удерживайте `?` (`Shift+/`, на русской раскладке — `.`),
  чтобы увидеть все сочетания, пока клавиша нажата.
- **Управление с клавиатуры** — воспроизведение, перемотка, громкость, дорожки,
  соотношение сторон, обрезка полей.
- **MPRIS2** — управление из виджета рабочего стола и мультимедийными клавишами.
- **Интерфейс на английском и русском** — переключается на лету.

## Зависимости

Для сборки:

| Зависимость | Примечание |
| --- | --- |
| Qt 6.5+ | Core, Gui, Quick, QuickControls2, Widgets, DBus, Network, OpenGL, OpenGLWidgets, LinguistTools |
| libmpv | пакет `mpv` / `mpv-libs` |
| TagLib | чтение и запись тегов аудиофайлов (`taglib`) |
| Библиотеки разработки FFmpeg | `libavformat`, `libavcodec`, `libswscale`, `libavutil` |
| CMake ≥ 3.16, Ninja (или Make), компилятор с C++17 | |

QML-модули, нужные только во время работы (CMake их **не** проверяет — приложение
падает с ошибкой импорта QML):

- `Kirigami` (`kirigami` / `kirigami2`);
- `qqc2-desktop-style` (стиль KDE для Qt Quick Controls).

Необязательно:

- `yt-dlp` — воспроизведение ссылок с видеосайтов;
- `avahi` (`avahi-browse`) и бинарник `ffmpeg` — Chromecast.

Arch Linux:

```bash
sudo pacman -S --needed base-devel cmake ninja qt6-base qt6-declarative qt6-wayland \
    kirigami qqc2-desktop-style mpv ffmpeg taglib
```

## Сборка

```bash
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
./build/bin/luma                       # бинарник в build/bin/, а не в build/
./build/bin/luma /путь/к/файлу.mkv     # сразу открыть файл
```

Установка в систему:

```bash
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=/usr
cmake --build build -j"$(nproc)"
sudo cmake --install build
```

## Пакет для Arch Linux

В репозитории есть `PKGBUILD`:

## Тесты

По умолчанию тесты **выключены** — при обычной сборке не собираются и в пакет не попадают.
Включаются явно:

```bash
cmake -B build -S . -DLUMA_BUILD_TESTS=ON
cmake --build build -j"$(nproc)"
ctest --test-dir build --output-on-failure
```

Набор на Qt Test проверяет основную логику: таблицу горячих клавиш, модель и менеджер
плейлистов, конфигурацию и файл настроек yt-dlp. Тесты работают с временным
`XDG_CONFIG_HOME`/`XDG_CACHE_HOME`, поэтому ваши настройки не затрагиваются. Qt6::Test
необязателен: если модуля нет, тесты просто не собираются.

## Использование

- **Открыть файл или папку** — правый клик по видео → *Открыть*, либо перетащите файл
  в окно, либо передайте путь в командной строке.
- **Открыть ссылку** — правый клик → *Открыть* → *Открыть по ссылке…*; yt-dlp
  разрешает поток, и Luma воспроизводит его в mpv. Перемотка работает как обычно.
- **Плейлисты** — кнопка плейлиста на панели управления открывает панель. Вкладки
  сверху переключают плейлисты; правый клик по вкладке — *Добавить файлы…*,
  *Добавить папку…*, *Очистить плейлист*, *Переименовать*, *Удалить*. Правый клик по
  записи — воспроизведение, перемешивание, «Добавить в плейлист», свойства, открытие
  папки с файлом и удаление из плейлиста.
- **Субтитры** — выбор дорожек в контекстном меню или горячими клавишами.
- **Трансляция** — *Воспроизведение → Устройство вывода* в контекстном меню.

## Настройки

Все пользовательские файлы лежат в `~/.config/luma/`:

| Файл | Назначение |
| --- | --- |
| `luma.conf` | Настройки приложения (INI) |
| `mpv.conf` | Дополнительные параметры mpv, подключаются при запуске |
| `yt-dlp.conf` | Параметры yt-dlp при открытии ссылок |
| `playlists/*.json` | Сохранённые именованные плейлисты |

Журнал пишется в `~/.cache/luma/luma.log`; в `[ui]` можно задать
`debug_logging=debug` для подробного вывода (или `none`, чтобы отключить).

Секции `luma.conf`:

```ini
[ui]
remember_volume=true
default_volume=80
volume=80
language=ru              # en, ru
single_instance=true
notifications=true
append_to_playlist=false
control_bar_mode=float  # hidden, float, pinned
show_panels_fullscreen=true
debug_logging=info

[playlist]
mode=sequential          # sequential, repeat, shuffle, stop

[window]
width=960
height=600

[subtitles]
font=sans-serif
size=55
bold=false
color=#FFFFFFFF         # #RRGGBB или #AARRGGBB
border_size=3
border_color=#FF000000
background=false
position=100            # 0..100, 100 = низ экрана
ignore_file_style=false
```

Эти ключи пишет вкладка «Субтитры» в настройках; выбор шрифта показывает системные
шрифты.

Вкладка «Воспроизведение» хранит `hwdec` и `ao` в `mpv.conf` в синтаксисе mpv
(`hwdec=...`, `ao=...`); автоматический аудиовыход — это отсутствие строки `ao`.
В старых версиях эти значения лежали в `luma.conf` в секции `[playback]`; при первом
запуске они переносятся в `mpv.conf`, а ключи из `luma.conf` удаляются. `no` в `hwdec`
отключает аппаратное декодирование.

`yt-dlp.conf` — по одной опции на строку, читается при каждой ссылке. Качество видео и
прокси задаются в *Настройки → Воспроизведение*; Luma записывает их в этот файл, сохраняя
остальные ваши строки, например:

```ini
--no-playlist
--format=bestvideo[height<=1080]+bestaudio/best[height<=1080]
--proxy=socks5://127.0.0.1:1080
```

Прокси задаётся типом (`SOCKS5`, `SOCKS5h`, `HTTP`, `HTTPS`) и адресом в виде
`host:port`. yt-dlp использует его для получения потока. Для SOCKS5 Luma дополнительно
поднимает локальный HTTP-мост: mpv качает поток (включая перемотку и Range-запросы) через
него, поэтому работает даже SOCKS-прокси без дополнительных утилит. HTTP-прокси
передаётся mpv напрямую. Файлы не скачиваются.

## Локализация

Строки лежат в `.ts`-файлах в `locales/` (`en`, `ru`). Японский и китайский временно
отключены. Чтобы добавить язык: создайте `locales/<lang>.ts`, добавьте его в
`qt_add_translations(...)` и в список `install(FILES ...)` в `CMakeLists.txt`, а также
в список языков в `qml/SettingsDialog.qml`.

Переводы этого README — в [`docs/readme/`](README.md).

## Если что-то не работает

- **Запуск второй копии ничего не делает.** Включён режим одного экземпляра: аргументы
  передаются уже запущенному плееру, а новый процесс завершается. Закройте работающий
  экземпляр или задайте `single_instance=false` в `luma.conf`.
- **Приложение не стартует на X11 или без графической сессии.** `main.cpp` принудительно
  включает платформенный плагин Wayland и OpenGL RHI.
- **Ошибка импорта QML при запуске.** Установите `kirigami` и `qqc2-desktop-style`.
- **Трансляция не находит устройства.** Проверьте, что установлены `avahi` и `ffmpeg`,
  а телевизор в той же сети.
