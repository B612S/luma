# README translations

The main `README.md` in the repository root is written in English. Translations live in
this folder and follow the naming scheme `README.<language-code>.md`:

| Language | File |
| --- | --- |
| English | [`../../README.md`](../../README.md) |
| Русский | [`README.ru.md`](README.ru.md) |

To add a language, copy the English README to `README.<code>.md`, translate it, and add a
row to the table above (and a link in the root README).
