Fallback icons for the Luma AppImage.

The SVGs in `actions/` and `status/` are from the KDE Breeze icon theme
(`breeze-icons`), licensed under LGPL-3.0-or-later:
https://invent.kde.org/frameworks/breeze-icons

They are bundled only so the AppImage's controls do not depend on the host's
icon theme. `view-list-symbolic.svg` is Breeze's `view-list-details-symbolic.svg`
renamed for the playlist button in the control bar; `view-media-playlist-symbolic.svg`
is Breeze's playlist icon used by the all-playlists dropdown in the tab bar.
